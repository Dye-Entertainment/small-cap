# Small Cap – Pip and the Sunstone

A short top-down action-adventure (about 10 minutes of play) built on the
[evogine](https://github.com/Dye-Entertainment/evogine) engine. Pip and Capo, a talking acorn
cap, shrink down to tiny size to win back the Sunstone from the Bramble Beetle.

All art, maps, sound effects and music are original and generated by the scripts in `tools/`.

## Controls

| Action              | Keyboard               | Gamepad |
|---------------------|------------------------|---------|
| Move                | Arrows / WASD          | D-pad   |
| Sword (hold: spin)  | Z / J / Space          | A       |
| Talk / open / read  | X / K                  | B       |
| Roll                | C / L / Shift          | X       |
| Start / pause       | Enter / P              | Start   |

On phones and tablets the browser version shows a touch D-pad with A (sword), B (talk), C (roll)
and START buttons (`?touch=1` / `?touch=0` in the address forces them on or off).

## The adventure

1. **Hearthwood** – get the sword from Elder Bram so the guard lets you pass.
2. **The Rootwood** – fight through the forest to the glowing shrink stump.
3. **Thimblewick** – a world at bug size: blades of grass, pebbles and acorns.
4. **Root Hollow** – a 7-room dungeon with block puzzles, a small key, a big key and the
   Bramble Beetle boss.

## Building

The engine is a git submodule (`evogine/`).

```sh
git submodule update --init --recursive
make evogen        # builds the engine's code generator (once)
make linux         # native build -> build-linux/Release/small-cap
make run
make web           # emscripten build (needs ~/emsdk) -> build-web/
make pages         # copies the web build to site/
make deploy        # pushes site/ to the gh-pages branch
make assets        # regenerates textures, maps, sounds and music
```

The maps in `resources/maps` are regular Tiled JSON files (tileset `resources/textures/tiles.tsj`),
so they can be opened in Tiled; `make assets` regenerates them from `tools/make_maps.py`.

### Test hooks

Environment variables for jumping around while developing:

- `SMALLCAP_AUTOSTART=1`: skips the title screen
- `SMALLCAP_MAP=woods`, `SMALLCAP_SPAWN=stump`: chooses the start point
- `SMALLCAP_POS=22.5,8.5`: sets the start position in tiles
- `SMALLCAP_SWORD=1`: starts with the sword
- `SMALLCAP_FLAGS=a,b`: sets story flags
- `SMALLCAP_PEACE=1`: removes regular enemies
- `SMALLCAP_INPUT="right:60 sword:1 wait:30"`: scripted input
- `SMALLCAP_SHOTS=120,300`: saves screenshots at those ticks, then quits
